# Script (narration)

The narration is written by the script skill that ships next to this one: `script/SKILL.md` (+ `script/references/
formula.md`, `script/references/examples.md`). Read it when you are asked to write or rewrite the script; for a build
the script already exists in `script.txt` and is voiced.

What the builder needs from it:
- Each line is one or two beats. `[SHOT: ...]` hints say what to show; follow them unless they can't be filmed.
- The format: "In this world, <rule>." hook -> 3-5 escalating literal examples (setup + consequence) -> a named hero ->
  a turn -> a complication -> a deadpan twist line (the last vine boom).
- Every clause is literal: if the script says "his nose hit the wall", the shot shows the nose hitting the wall.
- Lengths: 35-52 s (most) or 105-115 s. ~2.6-3 words per second.
