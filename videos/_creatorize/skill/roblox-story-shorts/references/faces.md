# Faces (decals in the project's `faces/`; `face: 'name'` on avatar() or any key)

Rule of the refs: the hero gets a NEW face on every beat (~every 1.5-2 s); side characters hold one face per scene;
reactions are exaggerated (bug eyes, screaming) while the hero stays deadpan / smug at the joke.

| name | use it for |
|---|---|
| classic_smile | calm default smile (alias `smile`) |
| happy_derp | big happy open grin, excited (`happy`) |
| goofy_tongue | goofy happy, tongue out (`grin`) |
| leo_smug | smug sideways half-lidded look, scheming, lying (`smug`) |
| dion_smirk | droopy eyes + small smirk, pretending to be fine |
| blonde_smug | side-eye smug smile, flirty |
| o_eyes | surprised round eyes, o mouth (`surprised`) |
| derp_o | derpy huge round eyes, tiny mouth: shocked (`shocked`) |
| bug_eyes | stressed bug eyes with bags (`nervous`) |
| sweat | nervous side glance with sweat drops (`scared`) |
| glasses_worry | glasses, worried stare (`worried`) |
| glasses_frown | glasses, flat unhappy stare, deadpan (`neutral`) |
| squint_frown | > < squint frown, straining (about to sneeze, pushing) |
| squint_mad | squinting grumpy frown, annoyed |
| noob_unamused | half-lidded, unimpressed, bored (`sleepy`) |
| noob_yell | V brows, yelling open mouth (`scream`) |
| noob_angry | outraged wide eyes + angry brows (`angry`) |
| mom_rage | screaming parent, wrinkles + huge teeth (`furious`) |
| mom_teeth | furious, gritted zigzag teeth |
| mom_red_eyes | red spiral eyes, losing it |
| teary | big watery pleading eyes, lonely, sad (`sad`) |
| moustache_sad | grumpy moustache frown with one tear (`cry`) |
| kid_cry | bawling, tears, clenched teeth (`sob`) |
| dad_moustache | curly-moustache dad (`moustache`) |
| dad_shock | bald dad shocked, moustache over an o mouth |
| sis_scared | huge eyes, frightened mouth |
| girl_o | star pupils, o mouth: amazed |
| meme_man | realistic stunned dread, awkward silence |
| mannequin_scream | black eyes, screaming: horror |
| nerd | glasses + buck teeth grin |
| evil | villain grin |
| monster | creature face |
| love | love-struck |

Aliases (old names still work): smile happy grin smug worried scared shocked surprised cry sob angry furious sad sleepy
neutral nervous scream moustache. Any other name draws a placeholder: don't invent names.
Skin colour is the avatar's `skin`; the decal is drawn on top, so every face works on every skin tone.
