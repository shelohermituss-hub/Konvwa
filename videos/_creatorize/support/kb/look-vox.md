# Vox look settings
keywords: vox, newspaper, collage, cut-out, cutouts, paper, paper and ink, press, sepia, broadsheet, paper texture, halftone, dots, film grain, grain, grainy, noise, vignette, warmth, too yellow, too orange, sepia tone, brown, shadows, cut-out shadows, sticker border, white border, camera creep, whip-pan, panels per row, pictures per minute, too many pictures, brand colour, red
platforms: both

Change these in the editor: **Look** button > change the setting > **Apply to project**. New videos start on **Press**;
the other looks are **Sepia archive** and **Broadsheet** (they change the defaults below).

- **Format**: Wide 16:9 or Vertical 9:16. Picked in New project, fixed afterwards.
- **Paper and ink**: **Press (cream + red)** (default), **Sepia (aged paper)**, **Broadsheet (white + red)**: paper,
  ink and stamp colours for everything.
- **Pictures per minute** (4 to 30, default 12 = one every 5 s): how busy the video is, how many cut-outs Claude makes
  per minute. Fewer = fewer pictures to make (and pay for on a paid picture service). Also set in New project.
- **Paper texture** (0 to 1, default 0.40): paper grain over everything. Set to 0 for clean paper.
- **Halftone print** (0 to 0.3, default 0.07): printed dot screen over the frame. Set to 0 for no dots.
- **Film grain** (0 to 0.1, default 0.035): film noise over the picture. Set to 0 for none.
- **Vignette** (0 to 0.5, default 0.16): darker edges. Set to 0 for none.
- **Warmth** (-1 to 1, default 0.15): below 0 cooler, above 0 warmer.
- **Sepia tone** (0 to 1, default 0): prints everything in sepia (brown).
- **Cut-out shadows** (0 to 0.6, default 0.32): how dark the soft shadows under cut-outs and paper are.
- **Sticker border** (0 to 2×, default 1.0×): width of the white hand-cut border around cut-outs. 0 = none.
- **Camera creep per shot** (0% to 10%, default about 4%): how much every shot slowly pushes in. 0% = still.
- **Whip-pan length** (0.35s to 1.20s, default 0.62s): travel time between panels.
- **Panels per row** (2, 3, 4 or 5; default 4 wide, 2 vertical): how the chapters sit on the front page.
- **Brand colour** (Style default): your channel colour instead of the red: stamps, dates, marker circles, tags and
  headlines.

**Sepia archive** is heavier (paper 0.60, vignette 0.30, sepia tone 0.55); **Broadsheet** is lighter (paper 0.18,
vignette 0.06). Cut-outs need a picture service: see "Image generation: Google Flow, Higgsfield, Fal.ai".
