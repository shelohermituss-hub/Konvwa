# Interface size, workspace folder and logs
keywords: too small, too big, text too small, make text bigger, bigger text, font size, text size, zoom, zoom interface, interface scale, ui scale, scale, display, workspace, where are my files, where are my projects, project folder, files location, documents, storage, disk, open log, log file, logs, diagnostics, copy diagnostics, version
platforms: both

Both are in **Settings > General**.

## Interface scale

Makes text and controls bigger or smaller: 67%, 75%, 80%, 90%, **100% (default)**, 110%, 125%, 150%, 175% or 200%.

Shortcuts anywhere in the app: Ctrl/⌘ + to make it bigger, Ctrl/⌘ - to make it smaller, Ctrl/⌘ 0 to reset. A small badge shows the new size; "Largest that fits this window" means the window is too small for more.

## Workspace

The folder where every project folder and the app's own files live. By default it is the **Creatorize Suite** folder in your Documents.

- **Open** shows it (On Windows: in File Explorer / On Mac: in Finder).
- The box under it shows what is inside.
- There is no setting to move it to another folder.
- One project's folder: open the project in the editor and click the folder button (**Open project folder**) at the top.

## Log and diagnostics

At the bottom of the Workspace row you see your version and system, then:

- **Open log**: the app's log file.
- **Copy diagnostics**: copies details about your setup. Paste them when you report a problem (**Help > Report a problem**).
