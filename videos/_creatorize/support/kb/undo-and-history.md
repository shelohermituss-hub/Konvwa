# Undo, revert and history
keywords: undo, revert, go back, undo edit, undo claude, broke my video, ruined, messed up, claude broke it, restore, restore to here, history, previous version, old version, get back old version, ctrl z, cmd z, redo, re-apply, reapply, before after, compare, view changes, what changed, backup, duplicate, can't be reverted, git missing
platforms: both

Every Claude edit is saved as its own step, so you can always go back exactly.

## Undo the last edit

- Click **Revert** on the edit's card in the Claude panel.
- Or press Ctrl/⌘ + Z (click outside the text box first). A message asks "Undo …?": click **Revert**.
- Changed your mind? **Re-apply** brings it back (on the card, or in the message), or press Ctrl/⌘ + Shift + Z.

## Undo an older edit, or go further back

1. In the Claude panel, open the **History** tab.
2. Under **Edits** each edit has **Changes** (what changed), **Revert** or **Re-apply**, and **Open** (its conversation).
3. Older edits also have **Restore to here**: it puts the project back exactly as it was before that edit. This undoes that edit and every edit after it; each can be re-applied later. Confirm with **Restore**.

Edits show **Applied**, **Reverted**, **Stopped**, **Failed** or **No changes**.

## Compare

Each edit has a Before / After picture: drag the slider across it. The time button under it jumps the preview there. On the timeline, purple notches mark where edits were made (grey once reverted).

## Before something big

Make a copy first: on the **Projects** page, click the copy icon (**Duplicate**) on the project's card, then try the big change on the copy.

## "Edits work, but can't be reverted"

Git is missing on this computer. Open **Settings > System > System check**: "Git (edit history)" says "Not found: edits cannot be reverted" and shows how to install it (see "System check and missing tools").
