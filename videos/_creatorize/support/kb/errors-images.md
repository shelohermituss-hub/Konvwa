# Image errors: Google Flow
keywords: google flow, flow, chrome, pictures, images, image generation, not set up, sign in, policy, blocked, unsafe, credits ran out, unusual activity, generate button, prompt box, did not finish, aspect ratio
platforms: both

## Flow is not set up
> Google Flow is picked but not set up on this computer yet...
> Open Flow in Chrome and finish signing in / the check, then try again...

Fix:
1. Open **Settings > Media > Google Flow** and click **Open Flow to sign in**.
2. Sign in with your Google account in the Chrome window that opens (finish any check Google shows).
3. Try again. Keep that Chrome window open while a video builds.

## Chrome is missing or not answering
> Google Chrome is not installed. Flow pictures need Chrome...
> Chrome started but did not answer. If a Flow Chrome window is already open, close it and try again.
> The Flow Chrome window was closed.

Fix: install Google Chrome (free from google.com/chrome; on Mac put it in Applications). If a Flow Chrome window is stuck, close it and try again.

## Flow blocked the picture
> Flow blocked this prompt (policy), nothing was charged. Change the prompt and try again.

Fix: change the wording of the picture (ask Claude to describe it differently), then try again.

## Credits or unusual activity
> Your Flow credits ran out for now. Check your plan in Flow, then try again.
> Flow refused this run (unusual activity). Open Flow in Chrome, make one picture there by hand, then try again.

Fix: follow the message. Without Flow credits, pick a paid service in **Settings > Media > Image generation** for now.

## Flow's page changed or was slow
> Flow did not show its prompt box...
> Flow's Generate button was not found...
> Flow did not finish the picture in ...
> Flow's aspect ratio could not be set to ...

What it means: Flow is driven through its own web page (at your own risk). The page was slow, not signed in, or Google changed it.

Fix:
1. Look at the Flow window in Chrome: make sure a project is open and you are signed in.
2. Try again.
3. Keeps failing? Click **Help > Report a problem** so it gets fixed.
