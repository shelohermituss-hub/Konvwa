# Using your own Claude Code session (Bridge)
keywords: bridge, enable bridge, own session, my own claude, terminal, claude desktop, desktop app, external claude, outside the app, use creatorize, connect claude code, claude code terminal, work on open project, selection, not running, listening on, bridge command
platforms: both

**Settings > AI engines > Bridge for your own sessions** lets a Claude Code session you already have open (the Claude desktop app or a terminal) see what you selected and work on the project open in Creatorize.

## Set it up

1. Make sure **Enable bridge** is on (it is on by default). It says "Listening on …" while it runs and "Not running" while it is off.
2. Click **Copy** next to the command shown.
3. Run that command once (On Windows: in PowerShell / On Mac: in Terminal).
4. In any Claude Code session, say: "use creatorize to fix what I selected".

## Good to know

- Open the project in Creatorize and select what you mean first; your session works on that open project.
- The command is needed only once, not every time.
- Turn **Enable bridge** off if you don't use it.
