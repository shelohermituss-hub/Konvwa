# Sessions settings (verify edits, library, own setup, turn limit)
keywords: sessions, session, check edits with rendered frames, verify edits, rendered frames, grow the library after builds, library, harvest, reuse, use my own claude code setup, own setup, my hooks, my skills, connectors, turn limit, turn limit per edit, max turns, edit stops early, claude stopped, ran out of turns, start over, new session, claude remembers
platforms: both

**Settings > AI engines > Sessions**. Each project has one Claude Code session that every edit continues, so Claude remembers the project. To start it over, click **+** in the project's Claude panel.

## Check edits with rendered frames

On by default. Claude renders the moments it changed and fixes what looks wrong.

## Grow the library after builds

On by default. When a video is built, Claude takes a short read-only look back and proposes what later videos can reuse (code, scene recipes, fixes). You accept or reject each in the **Library**. **Library > Harvest now** works either way.

## Use my own Claude Code setup

Off by default. Off keeps sessions fast and focused on the app's own tools. On also loads your personal Claude Code setup (your hooks, personal skills, instructions, connectors). ChatGPT runs follow it too. Turn it on only if you need something from your own setup.

## Turn limit per edit

How many steps one edit may take: 5 to 400, default **60**. Type a number and click outside the field. If big edits stop before they are done, raise it.
