# Command palette (Ctrl/⌘ + K)
keywords: command palette, search, search or run, quick search, ctrl k, cmd k, ⌘k, jump to page, find setting, find project fast, open project quickly, shortcut, quick open, go to, search bar, search box, spotlight, palette not opening, no results
platforms: both

The command palette finds any page, project, channel or setting and runs common actions from the keyboard.

## Open it

- Press Ctrl/⌘ + K anywhere (not while another dialog is open), or
- Click **Search or run…** near the top of the sidebar.

## Use it

1. Type a few letters of what you want. Accents don't matter.
2. Move with the Up and Down arrow keys.
3. Press Enter (or click) to run it. Esc closes the palette.

## What you can find

- **Actions**: **New project** (Personal Brand: **New video**), **Import a project folder** (Faceless Brand).
- **Switch to Personal Brand** / **Switch to Faceless Brand**.
- **Pages**: every page of the sidebar, plus **Settings** and **Open editor** while a project is open.
- With a Faceless Brand project open: **Graphics for "..."** (its quality and post-processing panel) and **Make the voiceover for "..."**.
- **Channels**: **All channels** and each of your channels, also found by its @handle.
- **Projects**: every project of the workspace you are in.
- **Settings**: once you type, up to five matching settings show as **Settings: ...**. Picking one opens Settings at that setting.

## No results?

"No results for ...": try a project name, a page like Renders, or "new". Projects of the other workspace are not listed: switch workspace first (it is in the palette too).

## Related shortcuts

- Ctrl/⌘ + N: new project or video.
- Press ? in the editor for all editor shortcuts (see "Keyboard shortcuts").
