# Import and share projects (.zip and folders)
keywords: import, import project, import folder, import zip, share, share project, share as zip, send project, zip, .zip, export project, backup, back up, move project, move to new computer, other computer, transfer project, open someone's project, shared project, drag and drop, not a creatorize project, not a suite project, project.json, restore backup, copy to laptop
platforms: both

You can pack a project into one .zip to send or back up, and bring in a .zip or a project folder. This is on the **Projects** page (Faceless Brand).

## Share a project as .zip

1. On the **Projects** page, click the card's **Share as zip** button (the package icon).
2. Pick where to save it and click Save.
3. The message says "Saved ... (scenes, audio and assets, without renders or history)". Click **Show** to see the file.

Not in the .zip: your exported videos and the edit history. Send an exported video separately (see the **Renders** page).

A project made in one of your own styles carries that style, so whoever imports it gets the style too.

## Import a .zip

**Projects** > **Import .zip**, pick the file. It opens in the editor.

## Import a project folder

1. **Projects** > **Import folder** (also **Import** on Home, or "Import a project folder" in Ctrl/⌘ + K).
2. Pick the project's own folder: the one that holds its files, not the folder above it.
3. The app copies it into your workspace and opens it. "The original folder is untouched."

## Good to know

- You can also drop a project folder or a shared .zip anywhere on the **Projects** page.
- With a channel picked in the Projects page's channel filter, the import lands in that channel.
- Importing the same folder or .zip again opens the copy you already have.
- An imported project starts a fresh edit history: earlier edits can't be reverted in it.
- Move to a new computer: **Share as zip**, copy the file over, then **Import .zip** there.

## Error messages

- "That folder has no project.json, so it is not a Creatorize project.": you picked the wrong folder. Pick the folder that holds the project's files.
- "That zip has no project.json at its top level, so it is not a Suite project.": the project's files are buried too deep in the .zip. Unzip it and use **Import folder** on the folder that holds the project's files.
