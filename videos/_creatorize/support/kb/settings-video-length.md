# Preferred video length
keywords: preferred video length, video length, length, duration, how long, minutes, seconds, runtime, script length, long video, short video, longer video, shorter video, 2 minutes, 10 minute video, default length, change length, script too long, script too short, minutes:seconds
platforms: both

**Settings > AI engines > Preferred video length** is the length new projects start with. Claude writes scripts to it and paces builds for it.

## Change it

1. Click the field and type the length as minutes:seconds, like `2:30` or `10:00`.
2. Click outside the field. It saves ("Saved.").

- Default: **2:00**.
- From 0:15 up to 60:00.
- A value it can't read says "Use minutes:seconds, e.g. 2:30." and goes back to the old one.

## One video only

Every project can change its own length; this setting is only where new projects start.
