# References: show Claude your own files
keywords: references, reference, attach, attachment, attach file, upload file, add file, my video, my footage, my image, my picture, pdf, audio file, mention, @ mention, at sign, @vid1, @img1, paperclip, show claude a picture, example image, reference image, file not found, relink, time range, 3d model, glb, fbx, not in this project
platforms: both

References point Claude at your own images, videos, audio files, PDFs or 3D models. Nothing is copied, so any size works (a one-hour video is fine).

## Add one

- Click the paperclip in the Claude box (or **Reference** in the Build and Ultraedit windows). In **References**, click **Add reference**, or paste a file path and click **Add path**.
- Or drop files on the References window. A video, audio file or PDF dropped on the Claude box becomes a reference too.
- Each one gets a tag such as @img1 or @vid1.

## Use one

1. Type @ in the box: your references show. Pick one, or **Add reference…**.
2. For a long video, name the part that matters: @vid1[1:02:00-1:02:20].
3. Send. Claude looks at it.

A mention with no matching reference shows "not in this project": Claude would not know what it means.

## Manage them

Each card in **References** has **Insert**, **Show in Explorer** (Windows) / **Show in Finder** (Mac), and the bin to remove it from the project (click again to confirm; your file is not touched).

Moved a file? Its card says "File not found": click **Relink…** and pick it again.

## 3D models

A dropped 3D model (for example .glb or .fbx) is imported into the project. Then tell Claude what it should replace.

## Just a quick picture

To show Claude a screenshot for one request, paste it (Ctrl/⌘ + V) or drop it on the Claude box: up to 4 images go with that request.
