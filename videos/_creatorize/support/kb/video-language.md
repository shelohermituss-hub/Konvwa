# Making a video in another language
keywords: language, languages, other language, spanish, french, german, polish, portuguese, italian, japanese, multilingual, several languages, english only, translate, foreign language, language of this video, can't write, missing letters, accents, fonts, wrong language, script in spanish, make it a spanish video
platforms: both

Each video has one language: Claude writes the script and the words on screen in it, the voice reads it and the app
times its words. Other languages than English are Premium.

## Turn on other languages

1. **Settings** > **General** > **Language**: pick **Several languages**.
2. Pick which language **New videos start in**.
3. Claude sets up transcription for those languages on this computer (it says when it is done; see "Transcription
   and languages").

## Pick the language of a video

- **New project** > **Language** (only shown with Several languages on). The help line says what will be in that
  language.
- In the editor, the language button in the top bar changes it later (shown with Several languages on, or for a
  video that is not in English). The script is not
  rewritten: if it is in another language, use **Rewrite script**. The button waits while Claude works on the video or
  the audio is being cleaned and timed.

## "<Style> can't write <language>"

Some styles' fonts lack the letters of some languages (e.g. ł, ą or ż). New project says so, names a style that can,
and won't create the video until you pick another style or language.

## English only, but my script is in Spanish

With English only on, pasting a script in another language shows a warning with **Make it a Spanish video** (the
language it found). Click it so the voice, timing and on-screen words follow the script. On Standard this is Premium.

Personal Brand videos are always edited in English.
