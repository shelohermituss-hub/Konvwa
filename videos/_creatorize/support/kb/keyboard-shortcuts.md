# Keyboard shortcuts
keywords: shortcuts, keyboard shortcuts, hotkeys, hot keys, keys, keybinds, key bindings, play pause, space bar, frame by frame, step frame, next shot, undo, redo, ctrl z, cmd z, zoom, zoom timeline, zoom preview, full screen, fullscreen, command palette, ctrl k, cmd k, find word, go to time, in out points, mute, export shortcut, hide panels, shortcuts not working
platforms: both

Press ? in the editor (or the keyboard button in the top bar) to see this list in the app. On a Mac, Ctrl is ⌘ and Alt is ⌥.

| Keys | What it does |
|---|---|
| Space | Play / pause |
| ← / → (with Shift: one second) | Step one frame |
| [ / ] | Previous / next shot |
| Home / End (Mac: fn + ← / fn + →) | Start / end |
| Shift + click | Add to the selection |
| Shift + drag on the timeline | Select a time range |
| Ctrl + wheel (Mac: ⌘ + scroll or pinch) | Zoom the timeline or the preview, where the mouse is |
| I / O, X | Set in / out point (snaps to a nearby shot edge), clear the range |
| = / - / 0 | Zoom the preview in / out / fit (Alt/⌥ + drag pans) |
| J / K / L | Back 2 s / pause / play (L again = 1.5×, 2×) |
| G | Go to a time |
| M | Mute |
| F | Full-screen preview |
| Ctrl/⌘ + F | Find a word in the narration |
| Ctrl/⌘ + E | Export |
| Ctrl/⌘ + B / J | Hide or show the left side / the Claude panel |
| Ctrl/⌘ + I | Ask Claude (jump to the box) |
| Esc | Clear the selection |
| Enter | Send to Claude (Shift + Enter = new line) |
| Ctrl/⌘ + Z | Undo the last Claude edit (asks first) |
| Ctrl/⌘ + Shift + Z | Re-apply the last reverted edit |
| Ctrl/⌘ + K | Command palette ("Search or run…") |
| Ctrl/⌘ + N | New project |

## A shortcut does nothing?

- In a text box, letters, Space and Ctrl/⌘ + Z belong to the box: click the preview or timeline first.
- With a window (dialog) open, the editor's keys wait until you close it.

Interface size, anywhere in the app: Ctrl/⌘ + = bigger, Ctrl/⌘ + - smaller, Ctrl/⌘ + 0 normal.
