# Wide 16:9 or vertical 9:16
keywords: format, aspect ratio, 16:9, 9:16, vertical, wide, landscape, portrait, shorts, reels, tiktok, youtube shorts, 1080x1920, 1920x1080, change format, switch to vertical, make it vertical, wrong format, sideways
platforms: both

The format is picked per video in **New project** (**Format**: **Vertical** 9:16 or **Wide** 16:9) and is fixed after
that: the scenes are laid out for it.

## Which styles make which

- **Vox**, **3D reconstruction**: Wide 16:9 or Vertical 9:16 (both start wide).
- **Flat explainer**, **Low poly shorts**: Vertical 9:16 or Wide 16:9 (both start vertical).
- **Pixel art**, **MS Paint stick figures**: Wide 16:9 only.
- **Your styles**: the formats the style was made for (the Import page lists them).

New project remembers the format you used last in each style.

Wide is 1920×1080 for YouTube and the web; vertical is 1080×1920 for Shorts, Reels and TikTok.

## Changing it later

- The Look window shows **Format** greyed out: it can't be changed in an existing video.
- Need a vertical version of a wide video? See "Vertical 9:16 versions and trailers".
- Or make a new project in the other format and reuse your script (**I have a script**).
