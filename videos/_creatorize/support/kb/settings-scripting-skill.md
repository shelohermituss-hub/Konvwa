# Your scripting skill (your own way of writing scripts)
keywords: your scripting skill, scripting skill, script skill, my skill, own skill, script style, script formula, script template, scriptwriting, copywriting, writing style, tone, hook, my prompt, instructions, add a file, add a skill folder, paste text, use my scripting skill, claude ignores my script style, script writing rules, per video
platforms: both

Have your own way of writing scripts (a Claude skill, a prompt, a formula)? Add it once in **Settings > AI engines > Your scripting skill** and Claude follows it every time it writes or rewrites a script: in New project, in Write the script, and in the Write script step of routines.

The app still sets the length, the language and the script's layout. Only the text is used; nothing in it is run.

## Add it

Pick one:
- **Add a file (.md or .txt)**
- **Add a skill folder** (a Claude skill folder with its main skill file)
- **Paste text**, then **Save**

Text files only, up to 1 MB. It says "Scripting skill added. Claude follows it from the next script."

## Once it is added

- The row shows its name, how many files and a preview.
- **Use my scripting skill** switches it on or off ("Off: Claude writes scripts the usual way").
- **Replace with a file**, **Replace with a folder** or **Paste instead** swap it.
- **Remove** deletes it.

## One video without it

Switch it off for that video only in New project (This project's settings), in the Write the script window, or in a routine's Write script step.
