# Characters (Flat explainer)
keywords: character, characters, main character, my character, mascot, random character, describe character, design with claude, change character, change with claude, character lab, default character, use as default, delete character, mo, no main character, remove character, without character, who stars, cast
platforms: both

Every Flat explainer video can star a main character from your library. Find it on **Styles** > **Flat explainer** >
**Characters** tab. Other styles: see "3D reconstruction characters" and "Low poly shorts characters".

## Your characters

- **Random character**: made instantly from the style's parts, yours alone. Every plan.
- Type a description and click **Design with Claude** (Premium): Claude designs it in a character lab, about 5-15
  minutes, and it appears in your list when done. Needs Claude connected.
- Click a character to see it: **Use as default** (new videos star it), **Change with Claude** (Premium: say what
  should change, then **Open lab and ask**), **Open its lab** / **Watch Claude design it**, **Delete**.
- **Mo** is built in: it can't be changed or deleted. The default character can't be deleted either.
- Deleting a character doesn't change videos that already use it.

## Character lab

A character lab is a special project where the shots show only the character: every pose, close up, walking and at
phone size. Ask Claude for changes in the chat; each finished change is checked and saved to your characters.
**Your characters** goes back to the list.

## Pick the main character for a video

In **New project** > **Main character**:
- one of **Your characters** (the default is marked **Default**),
- **A random new character** (made with the project and added to your characters),
- **Describe a new character…** (Premium; Claude designs it, the build waits for it),
- **No main character (decide later)**: each scene gets its own people and objects.

## Change it later

In the editor click **Project settings** > **Main character**: the character's name (on) or **No main character**.
The next build follows. This only switches the character on or off; there is no button to swap in another
character for an existing video.
