# Style Studio: make your own look with Claude
keywords: style studio, studio, new look, own look, my own look, make a look, custom look, look with claude, references, reference images, critic, run until good, pin issue, approve, save look, studio stuck, stages, picture cap, new style, make a style, create style, from scratch, publish style, can't publish, old workspace
platforms: both

The Style Studio makes **looks** with Claude: the same style with your own settings (colours, grade, grain, camera,
captions, characters) plus notes for Claude. Nothing new gets drawn. Premium.

A whole new style (new elements, new sets) is not made in the app any more: it is built in Claude Code with the Style
Kit and then imported. See "Custom styles and the Style Kit".

## Start a look

1. Open **Styles**, then click **New look** on a style's card (Built-in or Custom tab).
2. Fill in **Name**, **Look for** (the style), **Frames** (**Wide 16:9** / **Vertical 9:16**), **Describe it**,
   **References** (optional images or videos) and the **Picture cap** (hidden when Google Flow makes your pictures).
3. Click **Start the look**.

## Stages

**Brief**, **Study**, **Look**, **Review**, **Save**.

**Run stage** lets Claude work; **Approve** moves on once the checks allow it. Click an earlier stage and **Go back to
it** to redo it. **Stop Claude** stops a run.

## Fixing what looks wrong

- Click the picture, describe the problem, **Pin issue**. Then **Fix it** on the issue, or **Fix all open**.
- **Run until good** runs fix rounds on its own, with the critic every few passes.
- **Next version** saves a version; **Compare** shows two side by side.

## Finish

**Save look**. It shows under its style in New project, the Look panel and Routines. Then **New project with it** or
**See it in Styles**.

## Older Studio workspaces

A workspace started before the Style Kit (a whole style) still opens and Claude can still work in it, but it can't
publish. Styles you already published keep working, and so do their videos.

Every Studio run uses Claude's top model at high effort or more, so it uses more of your Claude plan.

"No image account is set up": set up a picture service (see "Image generation: Google Flow, Higgsfield, Fal.ai").
