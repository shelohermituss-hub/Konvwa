# Vox editorial (old) look settings
keywords: vox editorial, old vox, vox editorial old, editorial, archive, newsroom, tabletop, colour theme, film grain, grain, grainy, halftone, paper texture, vignette, lifted blacks, washed out, grey blacks, warmth, camera drift, field of view, parallax, soft shadows, shadow softness, legacy style
platforms: both

Vox editorial (old) is the older paper collage style. Old projects still open and edit, but new videos can't use it
(new ones use **Vox**). Change these in the editor: **Look** button > change the setting > **Apply to project**.

Looks: **Editorial** (default), **Archive**, **Newsroom**, **Tabletop**, **Editorial wide**.

- **Format**: Vertical 9:16 or Wide 16:9, fixed when the project was made.
- **Colour theme**: **Editorial (cream + yellow)**, **Archive (sepia + wax red)**, **Newsroom (white + red)**,
  **Tabletop (bold + yellow)**.
- **Film grain** (0 to 0.12, Editorial 0.045). Set to 0 for none.
- **Halftone screen** (0 to 0.5, Editorial 0.14): printed dot texture. Set to 0 for none.
- **Paper texture** (0 to 1, Editorial 0.30). Set to 0 for clean paper.
- **Vignette** (0 to 0.7, Editorial 0.30): darker edges.
- **Lifted blacks** (0 to 0.15, Editorial 0.06): blacks become dark grey. Set to 0 for true black.
- **Warmth** (-1 to 1, Editorial 0): below 0 cooler, above 0 warmer.
- **Camera drift per shot** (0% to 12%, about 5%): how much every shot creeps in.
- **Field of view** (18° to 45°, Editorial 28°): lower = flatter collage, higher = more depth between layers.
- **Transition length** (0.20s to 0.90s, Editorial 0.42s).
- **Soft shadows** (on): paper layers cast soft shadows on each other.
- **Shadow softness** (0.3× to 2.5×, Editorial 1.0×).
- **Brand colour** (Style default): your channel colour for the highlights and accents.
